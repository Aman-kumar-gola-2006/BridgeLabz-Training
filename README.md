## 🔹 Week 1 – Day 2: Java Collections Framework

### 📌 List Interface

* Reverse list without built-in methods
* Frequency counting using `Map`
* Rotate elements by K positions
* Remove duplicates (order preserved)
* Find Nth node from end (two-pointer logic)

### 📌 Set Interface

* Set equality (order-independent)
* Union, intersection, symmetric difference
* HashSet → Sorted List
* Subset verification

### 📌 Insurance Policy Management System (Set-Based)

* `HashSet` → fast lookup
* `LinkedHashSet` → insertion order
* `TreeSet` → expiry-date sorting

Features:

* Unique policy tracking
* Expiry filtering (30 days)
* Coverage-based retrieval
* Duplicate detection
* Performance comparison

### 📌 Queue Interface

* Reverse queue using queue ops only
* Generate first N binary numbers
* Hospital triage simulation (`PriorityQueue`)
* Stack using two queues
* Circular buffer implementation

### 📌 Map Interface

* Word frequency counter
* Invert map (handle duplicates)
* Key with maximum value

* Group employees by department
